## 一、矩阵使用说明

### 1.1 关系类型对照表

| 符号 | 关系类型 | 含义 | 颜色标识 |
|------|---------|------|---------|
| 🔴 | 矛盾 (Conflict) | 两个需求相互冲突，无法同时满足 | 红色 |
| 🟡 | 重叠 (Overlap) | 两个需求有重复内容 | 黄色 |
| 🔵 | 依赖 (Dependency) | 一个需求依赖另一个 | 蓝色 |
| 🟢 | 前置 (Predecessor) | 一个需求必须先完成 | 绿色 |
| ⚪ | 独立 (Independent) | 无直接关系 | 灰色 |
| - | 自身 | 不适用于自身 | - |

### 1.2 填写规则

1. **上三角 vs 下三角**: 仅填写上三角（或下三角），避免重复
2. **双向关系**: 如存在双向关系（如矛盾、依赖），在两个交叉格都填写
3. **不确定时**: 标记为"⚪ 独立"，后续分析确认
