# ADR-003: Tauri 壳最低维护

## 状态
🔄 实施中

## 日期
2026-05-05

## 背景
Tauri 端代码需要保持最低维护量，避免业务逻辑污染。

## 决策
Tauri 壳仅承担窗口管理和系统能力调用：
- Rust 代码 ≤ 200 行
- 无业务逻辑，仅做窗口管理
- 不承载任何 UI 逻辑

## 理由
1. **简化维护**：Tauri 代码量小，易于理解和维护
2. **分离关注**：业务逻辑集中在 Web 层
3. **技术匹配**：Rust 适合系统级操作，不适合业务逻辑

## 当前实现
```
src-tauri/src/main.rs
├── 窗口创建和配置
├── 托盘菜单
├── 全局快捷键
└── 版本标识设置（约 210 行）⚠️
```

> **注意**: 当前 Rust 代码约 210 行，超过 G1 目标（≤ 200 行）。正在进行代码优化，目标是将 Rust 代码控制在 200 行以内。

## 后果
- ✅ 维护成本低
- ✅ 技术栈清晰
- 🔄 复杂系统能力调用受限（如需 Rust 实现）- 正在优化
- ⚠️ 当前 210 行超过 G1 目标（≤ 200 行），优化中
