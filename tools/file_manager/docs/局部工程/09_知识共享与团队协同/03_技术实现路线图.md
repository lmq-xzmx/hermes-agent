# 技术实现路线图

> **创建日期**: 2026-05-18
> **状态**: 规划中
> **目标**: 明确各阶段技术实现内容和依赖关系

## 一、整体阶段划分

| 阶段 | 周期 | 目标 |
|------|------|------|
| **Phase 0: 基础** | 2 周 | 统一账号 + 基础同步骨架 |
| **Phase 1: MVP** | 4 周 | 完整团队协作 + Web 界面 |
| **Phase 2: Beta** | 4 周 | Obsidian 集成 + AI 搜索 |
| **Phase 3: 正式版** | 4 周 | LLM Wiki 完整功能 + API 开放 |

---

## 二、Phase 0: 基础（2 周）

### 2.1 目标
搭建统一账号体系和同步服务骨架，为后续功能奠基。

### 2.2 任务分解

```
Week 1: 统一账号服务
├── [P0] Auth Service 独立部署
│   └── 文件: services/auth_service.py (已有，扩展 OAuth)
├── [P0] 用户表扩展
│   └── 新增: oauth_provider, oauth_id, phone
├── [P0] JWT Token 扩展
│   └── 新增: teams 列表, jti (token ID)
├── [P1] OAuth 提供商集成 (Google/GitHub)
│   └── 文件: services/oauth_service.py (新建)
└── [P1] 第三方绑定表
    └── 新增: user_bindings 表

Week 2: 同步服务骨架
├── [P0] SyncService 实现
│   └── 文件: services/sync_service.py (已创建骨架)
├── [P0] 同步 API 端点
│   └── 4 个端点: status/snapshot/delta/resolve (已创建)
├── [P1] 本地文件扫描 (build_local_snapshot)
│   └── 实现: 扫描 space 目录，构建 FileEntry 列表
├── [P1] Delta 计算 (compute_delta)
│   └── 实现: 对比本地/远端差异，检测冲突
└── [P0] 前端 API 方法
    └── 文件: web/src/services/api.js (已添加 4 个方法)
```

### 2.3 交付物
- Auth Service 可处理邮箱 + OAuth 登录
- SyncService 可计算文件差异
- 4 个同步 API 端点可用

### 2.4 验收标准
- [ ] 用户可通过 Google 账号登录
- [ ] SyncService.compute_delta() 返回正确差异
- [ ] 前端可调用所有 4 个同步端点

## 四、Phase 2: Beta（4 周）

### 4.1 目标
Obsidian + Claudian 集成，AI 搜索可用。

### 4.2 任务分解

```
Week 1-2: Obsidian 集成
├── [P0] Obsidian 采集器 (Collector)
│   └── 新建: tools/obsidian_collector/
│       ├── collector.py (文件监听)
│       ├── formatter.py (MD 转换)
│       └── sync_client.py (调用 Hermes API)
├── [P0] Collector 配置管理
│   └── 支持: config.yaml 多账号配置
├── [P1] 双向同步 (bidirectional)
│   └── 扩展: SyncService
└── [P1] 冲突解决策略
    └── 支持: Last-Write-Wins / Manual Merge / Keep Both

Week 3: Claudian 插件改造
├── [P1] Claudian Hermes 配置
│   └── 新建: claudian_hermes_plugin/
│       ├── settings.ts (Hermes 后端配置)
│       ├── sync_command.ts (同步命令)
│       └── file_api.ts (Hermes API 调用)
├── [P1] Claudian 登录模块
│   └── 新增: Hermes 登录弹窗
└── [P2] Claudian 同步 UI
    └── 新增: 同步状态面板

Week 4: AI 搜索
├── [P0] LLM Wiki Query API
│   └── 已有: /knowledge/search
├── [P0] 语义搜索实现
│   └── 已有: knowledge_service.py
├── [P1] 搜索结果高亮
│   └── 新建: web/src/components/SearchHighlight.vue
└── [P1] 搜索建议 (autocomplete)
    └── 已有: /knowledge/suggestions
```

### 4.3 交付物
- Obsidian 采集器可在后台运行
- Claudian 可连接 Hermes 后端
- 语义搜索返回相关结果

### 4.4 验收标准
- [ ] Obsidian 笔记变化 5 秒内同步
- [ ] Claudian 可触发同步到 Hermes Space
- [ ] 搜索 "LLM 架构" 返回相关笔记

## 七、技术债务

| 技术债务 | 影响 | 解决时机 |
|---------|------|---------|
| Gateway 配对码与 JWT 不兼容 | 无法统一身份 | Phase 1 |
| LLM Wiki 无认证 | 安全风险 | Phase 0 |
| File Manager JWT 无 refresh token 轮换 | 安全风险 | Phase 0 |
| 同步使用文件锁，非数据库锁 | 并发问题 | Phase 2 |
