# 员工入职引导 Checklist

> **创建日期**: 2026-05-24
> **用途**: 引导 IT 经验不足的员工完成知识库入职
> **预计耗时**: 5-10 分钟

---

## 一、入职三步骤

员工入职第一天，只需完成以下 3 步即可完成知识库入职：

### 📋 第 1 步：打开 Obsidian

**操作**：双击桌面 Obsidian 图标

**预期结果**：
- 显示欢迎引导动画
- 自动连接到团队知识库

**成功标志**：
```
🎉 欢迎加入公司知识库！
你的知识库已自动连接到「XX部门」团队。
```

---

### 📋 第 2 步：写第一篇笔记

**操作**：
1. 点击左侧「新建笔记」按钮
2. 输入标题：「我的第一天工作笔记」
3. 写几句话
4. 按 `Ctrl+S` 保存

**背后自动发生**：
- Claudian 自动解析笔记内容
- 过滤 `personal` / `draft` 标签
- 增量同步到团队 Space
- 触发 LLM Wiki 编译

**成功标志**（右下角短暂提示，2秒后消失）：
```
✅ 已同步到团队知识库
```

---

### 📋 第 3 步：完成 Check-in

**操作**：
1. 按 `Ctrl+P` 打开命令面板
2. 输入 `@hermes check-in`
3. 按回车执行

**预期结果**：
- 显示入职确认表单
- 勾选已完成的项目
- 点击「提交完成」

**成功标志**：
```
✅ 知识库入职完成！
你的笔记已与团队共享。
```

---

## 二、快速参考

### 常用操作

| 操作 | 快捷键 |
|------|--------|
| 新建笔记 | `Ctrl+N` |
| 保存笔记 | `Ctrl+S`（自动同步） |
| 搜索团队知识库 | `Ctrl+P` → `@hermes search-wiki` |
| 查看同步状态 | 右下角提示 |
| 完成入职确认 | `Ctrl+P` → `@hermes check-in` |

### 个人内容标记

如需标记个人内容（不共享给团队）：

```yaml
---
title: 我的私人笔记
tags: [personal]    # 添加 personal 标签
---
```

**说明**：带有 `personal` 标签的笔记不会同步到团队。

---

## 三、异常处理

| 情况 | 解决方式 |
|------|----------|
| 右下角显示黄色「离线模式」 | 检查网络连接，等待自动重连 |
| 同步失败提示 | 稍后重试，或联系 IT |
| 需要帮助 | 联系 IT：it-support@company.com |

---

## 四、常见问题

### Q: 我的笔记会自动同步吗？
**A**: 是的，按 `Ctrl+S` 保存后自动同步到团队，无需手动操作。

### Q: 哪些内容不会同步？
**A**: 带有 `personal` 标签的笔记不会同步。如需标记个人内容，添加 `tags: [personal]` 到 front matter。

### Q: 可以查看谁访问了我的笔记吗？
**A**: 可以，联系 IT 部门查看审计日志。

### Q: 离职后我的笔记怎么办？
**A**: 个人笔记（带 `personal` 标签）可导出。团队共享内容保留在公司知识库。

---

## 五、完成确认

完成以上 3 步后，即表示知识库入职完成。

你的笔记已与团队共享，同事可以在知识库中搜索到你的内容。

**下一步**：开始正常工作中使用 Obsidian 记录笔记吧！
