## 一、产品定位

### 1.1 一句话定位

**Hermes TeamSpace** — 面向团队的 AI 知识协作平台

让团队拥有一个**共享知识库**，LLM 自动编译整理，成员通过 Obsidian 或 Web 界面协作。

### 1.2 核心价值主张

| 用户痛点 | 我们的方案 |
|---------|-----------|
| 团队知识散落在个人笔记里，无法共享 | 统一知识库，按团队/空间隔离 |
| Obsidian Vault 无法多人协作 | Hermes SyncService 支持多设备双向同步 |
| LLM Wiki 无账号体系，无法区分权限 | 统一 JWT 账号 + RBAC 权限 |
| 知识积累靠人工整理，效率低 | LLM Wiki 三层架构自动编译 |
| 团队成员贡献无法追溯 | 完整的审计日志和变更记录 |

### 1.3 目标客户

| 客户类型 | 使用场景 |
|---------|---------|
| **创业团队** | 5-20 人，知识积累和共享 |
| **研究机构** | 论文、文献、研究笔记协作 |
| **内容团队** | 内容素材库、选题协作 |
| **技术团队** | 架构文档、技术方案协作 |
| **个人知识工作者** | 多设备同步，跨设备访问 |

## 四、竞争优势

### 4.1 差异化优势

| 竞品 | 我们的优势 |
|------|---------|
| **Notion** | 更强的 AI 编译能力（LLM Wiki vs RAG）、Obsidian 深度集成 |
| **Obsidian Sync** | 多人协作、RBAC 权限、审批流程 |
| **Confluence** | 轻量、LLM 原生支持、低成本 |
| **飞书知识库** | 开源、可私有部署、自定义模型 |

### 4.2 技术护城河

| 技术 | 护城河 |
|------|--------|
| **LLM Wiki 三层架构** | 编译层是核心，竞品难以复制 |
| **Hermes SyncService** | 双向同步 + 冲突检测，健壮性强 |
| **Obsidian 插件生态** | Claudian 插件形成生态锁定 |
| **MCP 协议集成** | AI Native 的工具调用标准 |

## 五、落地路径

### 5.1 MVP 版本（1-2 月）

```
MVP 功能集：
├── 统一账号（JWT + OAuth）
├── 团队 Space（创建、成员邀请、RBAC）
├── 基础同步（单向 push/pull）
├── Web 知识浏览（只读）
└── 定价：Free + Pro

目标用户：5-10 人创业团队
验证指标：注册率、周活跃、同步使用率
```

### 5.2 Beta 版本（3-4 月）

```
Beta 功能集：
├── Obsidian + Claudian 集成
├── 双向同步 + 冲突解决
├── AI 辅助搜索（Query）
├── 审计日志
└── 定价：添加 Team 套餐

目标用户：20-50 人中型团队
验证指标：团队留存率、协作频次
```

### 5.3 正式版（5-6 月）

```
正式版功能集：
├── LLM Wiki 完整编译（Ingest/Compile/Lint）
├── API 开放平台
├── 私有部署方案
├── 移动端
└── 定价：完整套餐 + Enterprise

目标用户：各规模企业
验证指标：收入、续费率、NPS
```
