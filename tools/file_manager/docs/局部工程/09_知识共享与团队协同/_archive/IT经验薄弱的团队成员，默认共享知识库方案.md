3.1 劳动合同条款示例
# 劳动合同补充条款（知识共享部分）

**第 X 条 知识资产共享**

1. **共享范围**：员工在任职期间，使用公司提供的 Obsidian 知识库系统
   所创建的全部工作相关内容（包括但不限于笔记、文档、代码片段、
   技术方案、项目记录等），默认与所在团队共享。

2. **隐私保护**：
   - 与工作无关的个人内容（如个人日记、家庭相关笔记）不在共享范围内
   - 员工可在知识库中标记为「个人」的内容，系统将自动排除同步
   - 公司不会查看员工的个人标记内容

3. **数据所有权**：
   - 共享内容的知识产权归属公司（与劳动合同约定一致）
   - 员工离职后，共享内容保留在公司知识库中
   - 员工可以导出个人知识库副本（不含公司机密）

4. **员工权利**：
   - 知情权：员工可随时查看谁访问了自己的知识
   - 申诉权：如认为某内容不应共享，可申请移除
   - 退出权：经主管审批，可调整为选择性共享模式

5. **违约责任**：违反共享规定的，按公司制度处理

  将个人笔记放在 vault/personal/ 目录下

  @hermes tag-personal --path "notes/daily/*"

  Ctrl+P → @hermes mark-personal
  → 当前笔记添加 tags: [personal]

八、一句话总结
对于 IT 经验不足的员工，方案调整为：

IT 预装：入职前完成所有配置（员工零操作）
引导式首次启动：打开 Obsidian → 自动弹出动画引导 → 按提示完成 3 步
保存即同步：员工只需正常写笔记、Ctrl+S，同步在后台自动完成
Checklist 驱动：通过简单的勾选框引导员工完成入职 Check-in
异常全自动处理：网络断开、Token 过期、冲突等全部静默处理

员工需要知道的操作只有三个：

Ctrl+N：新建笔记
Ctrl+S：保存笔记（自动触发同步）
Ctrl+P → @hermes check-in：完成入职确认

员工感觉就像在使用一个“自带团队协作功能的 Obsidian”，实际上背后是一套完整的企业知识管理平台。
