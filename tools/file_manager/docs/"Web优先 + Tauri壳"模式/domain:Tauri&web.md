### 1.7 IPC机制（来自 GOALS.md v2.1）

| 机制 | 说明 |
|------|------|
| **Commands/invoke** | 前端通过`invoke()`调用Rust函数 |
| **Events** | Rust主动推送事件到前端 |
| **window.__TAURI__** | 环境检测，区分Web/Tauri运行时的API_BASE路径 |

### 1.5 部署模式

#### 嵌入模式（当前）

```
web/dist → 打包进 Tauri app bundle → /Applications/Hermes File Manager.app
```

- Tauri 从 app bundle 本地加载 web/dist
- ✅ 离线可用
- ❌ Web 更新需要重新打包 Tauri

#### 独立部署模式（演进后）

```
Web → 部署到 Vercel/Netlify
Tauri → WebView 加载 https://your-app.vercel.app
```

- ✅ Web 更新无需重新打包 Tauri
- ❌ 需要网络连接

### ADR-001: Web 作为 SSOT

| 项目 | 内容 |
|------|------|

| 项目 | 内容 |
|------|------|
| **日期** | 2026-05-04 |
| **决策** | 使用 `vue.html` 作为主窗口 URL，`floating-vue.html` 作为浮窗 URL |

### ADR-003: CSP 保留 unsafe-inline

| 项目 | 内容 |
|------|------|
| **日期** | 2026-05-04 |

| **理由** | Vite 生产构建需要内联样式 |
| **状态** | ✅ 已接受 |
